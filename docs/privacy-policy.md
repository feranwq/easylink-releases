# EasyLink 隐私政策

最后更新：2026 年 10 月 31 日

本政策适用于 EasyLink iOS 应用及其分享扩展、快捷指令和通知扩展。EasyLink 是客户端软件；同步和通知服务由用户自行配置的 EasyLink 兼容服务器提供。本项目维护者不运营供本应用使用的统一剪贴板或通知服务器，也不会从本应用接收用户的剪贴板内容。

## 1. 我们处理哪些信息

### 用户在设备上保存的信息

- 用户添加的服务器地址、API Key 和别名保存在 iOS 应用共享容器的本地设置中，供 EasyLink 主应用、分享扩展、快捷指令和通知相关功能使用。请妥善保管 API Key；任何能访问该 Key 的人都可能以你的身份访问对应服务器。
- 通知历史、剪贴板历史元数据、快捷指令/通知处理状态及必要的同步标识可能保存在设备或应用共享容器中。
- 剪贴板历史元数据最多缓存最近 200 条。按需下载的历史文件缓存在设备上，缓存上限为 200 MB，或在文件超过 30 天后清理；空间不足时优先清理最久未访问的文件。

### 用户主动同步的剪贴板和文件

EasyLink 不会在后台持续读取或监控剪贴板。用户点击上传、下载、分享或运行相应快捷指令时，应用才会处理该操作所需的内容。用户选择或分享的文本、图片、视频和文件，以及相关的文件名、大小、内容哈希和时间等同步元数据，会发送到当前选中的服务器。

大文件可能通过服务器签发的临时传输地址直接上传或下载。该地址可能指向服务器运营者配置的对象存储服务，而不一定与 API 服务器属于同一主机。传输目标、服务器端保存时间、备份和删除方式由该服务器及存储服务的运营者决定。

### 通知与设备信息

如果用户启用通知，EasyLink 会向当前选中的服务器注册 Apple 推送通知令牌、稳定的安装/路由标识、服务器返回的设备标识，以及通知能力和必要的同步状态，以便该服务器向本设备投递通知。发送通知时，通知标题、正文、分组等用户提交的内容会发送给该服务器。服务端随后可能通过 Apple Push Notification service（APNs）向设备发送推送；Apple 会按其自身隐私政策处理推送令牌、推送负载及必要的网络信息。

通知历史会保存在设备上。查看、点击、已读等状态可能在用户操作后回传到当前服务器。通知中若包含外部图片 URL，系统通知扩展可能按需从该 URL 下载图片；该 URL 的运营者会收到常规网络请求信息，例如 IP 地址和请求时间。

### 网络与第三方服务

- EasyLink 将 API Key 通过授权请求头发送到用户配置的服务器，不会把它发送到 EasyLink 项目维护者运营的服务器。
- EasyLink 不包含广告 SDK 或第三方分析/追踪 SDK。Apple 可能根据用户的系统设置及 Apple 服务条款处理 App Store、TestFlight、APNs 和系统诊断相关信息。
- 用户主动打开的 GitHub、iCloud 快捷指令或通知中提供的外部链接，由相应服务运营者按其隐私政策处理访问数据。
- 若用户配置的服务器使用外部对象存储或其他第三方服务，该服务的数据处理由服务器运营者及相关服务运营者负责。

## 2. 使用目的与共享

上述信息仅用于保存用户配置、同步用户主动选择的剪贴板内容、传输文件、投递通知、显示历史记录，以及维持设备注册和通知回执。EasyLink 项目维护者不出售用户数据，也不会将其用于广告画像。用户主动选择的服务器及其运营者会收到完成所选功能所需的数据；APNs 和服务器配置的对象存储服务也可能参与相应传输。

## 3. 保存期限和删除

- 设备上的服务器配置、通知历史和其他本地数据会保留到用户在应用中删除/清理，或卸载应用并由 iOS 清除应用数据为止。iOS 系统剪贴板是否经 iCloud 与其他设备同步由用户的 Apple 设备设置决定。
- 剪贴板历史文件缓存按本政策第 1 节所述容量和时间规则清理；历史元数据缓存限制为最近 200 条。
- 服务器上的剪贴板内容、文件、通知和设备记录由用户所选服务器运营者控制。用户可使用应用中提供的清理/删除功能；如需删除服务器备份或应用无法删除的数据，应联系该服务器运营者。EasyLink 项目维护者无法直接访问或删除自建服务器上的数据。
- 用户可在 iOS“设置”中撤销 EasyLink 的通知权限，并可在应用中删除 API Key/服务器配置。删除 API Key 不一定会立即删除服务器上已保存的数据或设备记录。

## 4. 安全

EasyLink 使用 iOS 应用沙盒和 App Group 限制本地数据访问。网络传输是否加密取决于用户配置的服务器地址：HTTPS 可保护传输，HTTP 不提供传输加密，应用不会强制所有自定义服务器使用 HTTPS。服务器和对象存储的安全由相应运营者负责。请勿在不信任的服务器上保存敏感信息。

## 5. 儿童隐私

EasyLink 不是面向儿童设计的服务。我们不通过应用主动收集儿童个人资料。

## 6. 政策更新与联系

应用的数据处理方式发生变化时，我们会更新本页面并修改“最后更新”日期。隐私相关咨询请使用 App Store 产品页面列出的开发者联系渠道。GitHub 仓库问题区是公开区域，请勿在那里提交 API Key、剪贴板内容或其他敏感个人信息。你也可以通过 [Release 仓库问题区](https://github.com/feranwq/easylink-releases/issues)联系维护者。
