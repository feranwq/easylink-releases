# EasyLink Privacy Policy

**Effective date:** 2026-10-31  
**Applies to:** The EasyLink Android version distributed through Google Play.

## 1. Data and Purposes

EasyLink is a clipboard and notification sync client for a server that you configure. To provide sync, the app processes the server URL and API key you add; clipboard text you choose to upload; files selected through Android's file picker or share menu; clipboard history and notifications returned by your server; and a random installation identifier used for notification routing. The API key and configuration are stored in the app's private storage.

## 2. Transmission and Recipients

Sync requests are sent to the server you enter in the app. Clipboard content is uploaded only when you initiate a sync action; notification and history content is received from that server. The app does not use a developer-operated relay or send a separate copy of this content to the developer. The developer does not operate or control the server you choose; its operator determines how data is processed, retained, and deleted. If you choose a server operated by the developer, that server will receive the data you submit. The app does not include advertising or product analytics SDKs and does not provide a default EasyLink cloud account service.

You may use an HTTPS or HTTP server. HTTPS encrypts network traffic between your device and the server. HTTP does not provide transport encryption, so other parties on the network may read or modify requests. Prefer a trusted HTTPS server.

## 3. Local Storage, Backup, and Deletion

The API key, server configuration, notification state, and some history metadata are stored in the app's private data; on-demand downloads are stored in the app cache. The Play version excludes the configuration containing API keys from Android cloud backup and automatic device-to-device transfer. You must add the server and API key again on a new device. You can remove API keys, clear local cache, or delete server history in the app. Uninstalling the app or clearing its data removes local data. To delete data on your server, use the app's delete actions or contact that server's operator.

## 4. Children and Policy Changes

EasyLink is not designed specifically for children. Material changes to this policy will be reflected in the in-app notice and the public policy page.
