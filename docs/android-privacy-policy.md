# EasyLink Android 隐私说明

**生效日期：** 2026-10-31

**适用版本：** 从 GitHub Releases 等渠道下载的 Android APK。

## 统计与更新

应用不集成第三方运营统计 SDK，不会在启动时上报应用使用统计。

自动检查更新默认关闭。用户手动检查更新，或在设置中主动开启自动检查后，应用会访问 GitHub Releases 查询版本信息；下载更新时会从 GitHub 下载 APK。

用户主动使用 FRPC 功能并启动组件下载时，应用会从 `xupdate.ppps.cn` 下载对应设备架构的组件。

## 同步与转发

剪贴板同步、剪贴板历史、用量查询和通知同步等功能会根据当前配置和使用情况，向用户配置的 EasyLink 服务器发送相应请求和数据；通知同步可能在后台运行。API Key 用于访问该服务器。

短信、通话和应用通知转发功能仅在用户授予相应权限、启用规则并配置发送通道后运行。应用会在本机读取完成规则所需的信息，例如短信号码和内容、通话号码和状态、通知来源应用及通知内容，再按用户配置发送到指定目标服务。开发者不是这些转发内容的收件方；应用不会将内容另行抄送到开发者的服务器或用于运营统计。开发者不运营或控制用户选择的目标服务，其数据处理、留存和删除规则由该服务运营者决定。若用户主动将目标配置为开发者运营的服务，该服务会收到用户提交的数据。请仅配置你信任的服务器和发送通道。

## 网络事件信息

当 Android 网络状态变化触发网络事件后台任务时，应用会通过 HTTPS 向 `api.ipify.org` 和 `api6.ipify.org` 查询公网 IPv4/IPv6 地址；这些服务可看到请求来源的公网 IP。当前实现会在检查网络转发规则前发起查询，因此即使没有匹配的网络转发规则，该查询仍可能发生。若网络触发规则匹配，应用可能会将网络类型、运营商/SIM 信息、Wi-Fi 名称及 IP 信息发送到用户配置的发送通道。

## 权限与本地数据

应用所需的系统权限用于对应功能。用户可在 Android 系统设置中查看或撤销权限；撤销后，相应功能可能无法使用。应用配置和历史数据按功能需要保存在本机，清理应用数据或卸载应用可能将其删除。

## 联系方式

隐私问题可通过 [EasyLink Android 项目的 GitHub Issues](https://github.com/feranwq/easylink-android/issues) 联系开发者。
