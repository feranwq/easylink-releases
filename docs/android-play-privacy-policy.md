# EasyLink 隐私政策

**生效日期：** 2026-10-31

**适用版本：** 通过 Google Play 分发的 EasyLink Android 版本。

## 一、数据及用途

EasyLink 是用于您自己配置服务器的剪贴板与通知同步客户端。为完成同步，应用会处理您添加的服务器地址和 API Key；您主动上传的剪贴板文本、通过系统文件选择器或分享菜单选择的文件；服务器返回的剪贴板历史和通知；以及用于服务器通知路由的随机安装标识。API Key 和配置保存在应用私有存储中。

## 二、数据传输与接收方

同步请求会发送到您在应用中自行填写的服务器。剪贴板内容仅在您发起同步操作时上传；通知和历史内容从该服务器接收。应用不使用开发者运营的中转服务，也不会将这些内容另行抄送给开发者。开发者不运营或控制您选择的服务器；其运营者决定数据的处理、留存和删除方式。若您选择开发者运营的服务器，该服务器会收到您提交的数据。应用没有内置广告或运营统计 SDK，也没有默认的 EasyLink 云端账号服务。

您可以使用 HTTPS 或 HTTP 服务器。HTTPS 会加密设备与服务器之间的网络传输；HTTP 不提供传输加密，网络中的其他方可能读取或修改请求内容。请优先使用可信的 HTTPS 服务器。

## 三、本地存储、备份与删除

API Key、服务器配置、通知状态和部分历史元数据保存在本机应用私有数据中；按需下载的文件保存在应用缓存。Play 版本不会通过 Android 云备份或设备间自动迁移备份包含 API Key 的配置。更换设备后需重新添加服务器和 API Key。您可以在应用中删除 API Key、清除本地缓存或删除服务器历史记录；卸载应用或清除应用数据会删除本地数据。服务器上的数据需通过应用提供的删除操作或联系该服务器运营者处理。

## 四、儿童与政策更新

EasyLink 并非专为儿童设计。隐私政策有实质变更时，会更新应用内说明及公开政策页面。

## 联系方式

隐私问题可通过 [EasyLink Android 项目的 GitHub Issues](https://github.com/feranwq/easylink-android/issues) 联系开发者。
